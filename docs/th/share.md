# ส่งแผนให้คนอื่น

หน้าเว็บรันอยู่ในเครื่องของคุณเอง เพื่อนร่วมทีมจึงเปิดลิงก์ของคุณไม่ได้ ถ้าอยากให้เขาดูแผน ให้ส่งสำเนาไปแทน หน้านี้อธิบายสำเนาสองแบบ และสิ่งที่อยู่ในแต่ละแบบ

จะทำสำเนา เปิด **⋮ → Export** บนหน้าเว็บ หรือบอก agent ให้ export แผนก็ได้

## ส่งเป็นไฟล์ HTML

ไฟล์ HTML ที่ export ออกมาเป็นไฟล์เดียว เปิดได้ในทุก browser แม้ไม่มีเน็ต ข้างในมีทุกภาพ ทุกขั้นตอน และทุกกล่อง คลิกดูไปมาได้เหมือนบนหน้าเว็บ แต่ไม่มีใครแก้ได้ และไม่มี agent คอยตอบคำถาม

ก่อน export เลือกได้ว่าจะใส่อะไรบ้าง

- **โค้ด** ที่กล่องชี้ไปในโหมดอธิบาย จะใส่ไปด้วย ถ้าไม่อยากใส่ เอาติ๊กที่ **ใส่โค้ดที่อ้างถึง** ออก
- **แชท** จะไม่ใส่ไป ถ้าอยากใส่ ติ๊ก **ใส่แชท**
- **ร่างการแก้ไข** ถ้ามี จะใส่ไปด้วย พร้อมป้ายบอกว่ายังไม่อยู่ในแผน ถ้าไม่อยากใส่ เอาติ๊กที่ **รวมร่างการแก้ไข** ออก

> **ควรรู้:** ไฟล์นี้ไม่มี address ของ server ไม่มี token (รหัสที่ใช้เปิดหน้าเว็บ) และไม่มี path ในเครื่องของคุณ มันโหลดอะไรจาก network ไม่ได้ เปิดไฟล์แล้วจึงไม่มีอะไรถูกส่งออกไปไหน

## พิมพ์เป็น PDF

กด **PDF** ใน Export print dialog ของ browser จะเปิดขึ้นมา พร้อม layout ที่จัดไว้สำหรับกระดาษ เริ่มจากทุกขั้นตอน ตามด้วยทุกภาพเรียงกัน แล้วปิดท้ายด้วยกล่องทั้งหมด เลือก **Save as PDF** เพื่อได้ไฟล์ ถ้าแผนมาจากโหมดออกแบบ PDF จะเริ่มด้วยทางเลือกที่คุณเลือกและเหตุผล

ภาพใหญ่จะถูกแบ่งเป็นส่วนๆ ให้ยังอ่านออก ถ้าชื่อในภาพจะพิมพ์ออกมาเล็กกว่า 7 pt PDF จะแสดงทั้งภาพเป็นภาพรวมที่มีเลขกำกับก่อน แล้วตามด้วยแต่ละส่วนในขนาดที่อ่านได้ map จะแบ่งตามโซน เส้นที่ออกนอกส่วนของมันจะกลายเป็น label บนกล่องแทน เช่น `→ Aurora · 5432 · ส่วน 3` ภาพแบบอื่นจะแบ่งตามช่องว่างระหว่างกล่อง

## ตรวจก่อนส่ง

สำเนามีแผนของคุณ และมีโค้ดด้วย ถ้าไม่ได้เอาออก ดูให้ทั่วก่อนส่ง และอย่าส่งแผนที่มีข้อมูลลูกค้า hostname หรือ secret ที่คุณไม่กล้าแปะที่อื่น

## แชร์ตัวแผนเอง

แผนทั้งหมดอยู่ในไฟล์เดียว คือ `plan.json` ใน folder ของแผน ถ้าเพื่อนร่วมทีมมี Walkboard ด้วย เขา copy folder นั้นไป แล้วรัน `walkboard open` กับมันได้ จะได้หน้าเว็บที่ใช้งานได้จริงบนเครื่องของเขาเอง
