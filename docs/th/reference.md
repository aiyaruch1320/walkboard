# Reference

หน้านี้รวมคำสั่งเบื้องหลัง Walkboard วิธีลิงก์เข้าไปยังจุดต่างๆ ของหน้าเว็บ เอกสารที่อธิบายรูปแบบของแผน และ Walkboard ใช้ token มากน้อยแค่ไหน คุณไม่ต้องรู้เรื่องพวกนี้ก็ใช้ Walkboard ได้ เพราะ agent รันคำสั่งให้เอง หน้านี้มีไว้สำหรับตอนที่อยากรู้ว่าข้างในทำงานยังไง

## คำสั่ง

ทุกคำสั่งรันด้วย `node skills/walkboard/bin/walkboard.mjs` ซึ่งด้านล่างย่อเป็น `…` ถ้าใช้จาก repository ที่ clone มา ให้รันจาก root ของ repository ทุกคำสั่งรับ `--help` เพื่อดูตัวเลือก

| คำสั่ง | ทำอะไร |
|---|---|
| `… check <dir>` | ตรวจ `plan.json` ในโหมดอธิบาย จะตรวจด้วยว่า `file:line` ทุกอันยังมีอยู่ และยังเป็นโค้ดเดิมที่เคยชี้ไว้ |
| `… set <dir> [plan \| step: \| node: \| constraint: \| option: \| criterion: \| source:<id>] key=value …` | แก้ field ในไฟล์ตรงจุด `key=` คือลบ field นั้น `settings.commit=auto` คือแก้ค่าข้างใน object และ `what='"0042"'` ทำให้ตัวเลขยังเป็นข้อความ |
| `… open <dir> [--no-browser]` | เปิด server หรือใช้ตัวที่รันอยู่แล้ว แล้วพิมพ์ลิงก์ออกมา |
| `… poll <dir> [--full] [--now \| --timeout s]` | รอข้อความจากหน้าเว็บ แล้วพิมพ์ JSON สั้นๆ บรรทัดละข้อความ `--now` พิมพ์สิ่งที่รออยู่แล้ว หรือ `[]` โดยไม่รอ `--full` เพิ่ม id เวลา และตำแหน่งของทุกกล่อง |
| `… reply <dir> [--node id \| --step id \| --option id [--criterion id]] <text>` | ตอบบนหน้าเว็บ ในบทสนทนาของกล่อง ขั้นตอน หรือช่องในตารางเทียบแบบนั้น `[[node:id]]`, `[[step:id]]`, `[[option:id]]` และ `[[plan]]` จะกลายเป็นลิงก์ |
| `… status <dir>` | แสดงลิงก์และข้อความที่รออยู่ |
| `… stop <dir>` | หยุด server |
| `… draft <dir> [clear [view] [change …]]` | พิมพ์สิ่งที่ร่างไว้ในโหมดร่าง หรือล้างออกเมื่อเข้าแผนแล้ว |
| `… export <dir> [--html file] [--no-code] [--no-draft] [--with-chat]` | เขียนสำเนาของแผนแบบอ่านอย่างเดียวเป็นไฟล์ HTML ไฟล์เดียว |
| `… icons` | แสดงชื่อ icon ที่ใช้ใน `icon` ได้ |

## ลิงก์เข้าไปยังจุดต่างๆ ของหน้าเว็บ

ต่อท้ายลิงก์ของหน้าเว็บด้วยค่าเหล่านี้ เพื่อเปิดที่จุดที่ต้องการ

- `&step=<id>` เปิดขั้นตอนนั้น ส่วน `&step=all` แสดงทุกขั้นตอน
- `&view=<id>` เปิดภาพนั้น
- `&node=<id>` เปิดกล่องนั้น
- `&theme=light` หรือ `&theme=dark` เลือกธีม

## รูปแบบของแผน

แผนคือไฟล์เดียว ชื่อ `plan.json` ไฟล์ด้านล่างอธิบายรูปแบบของมัน ไฟล์เหล่านี้เขียนไว้ให้ agent อ่าน จึงตั้งใจเขียนให้สั้น (เป็นภาษาอังกฤษ)

- [schema.md](../../skills/walkboard/references/schema.md) อธิบาย `plan.json`
- [views.md](../../skills/walkboard/references/views.md) และโฟลเดอร์ [views/](../../skills/walkboard/references/views/) อธิบายภาพแต่ละแบบ
- [profiles/](../../skills/walkboard/references/profiles/) อธิบายชนิด (kind) ของแต่ละแพลตฟอร์ม

ใน repository มีแผนตัวอย่างให้เปิดอ่านได้ ข้อมูลทั้งหมดเป็นของสมมติ

| ตัวอย่าง | แสดงอะไร |
|---|---|
| `examples/nightly-import` | แผน |
| `examples/explain-login` | คำอธิบาย พร้อมโค้ดตัวอย่าง |
| `examples/connect-vpcs` | การออกแบบ |
| `examples/big-map` | map ขนาดใหญ่ |
| `examples/walkboard` | แผนที่ใช้สร้าง Walkboard เอง เป็นภาษาไทย |

## Tokens

**token** คือหน่วยที่โมเดลใช้นับข้อความ ยิ่งใช้น้อยยิ่งถูกและเร็ว Walkboard ออกแบบมาให้ใช้ token น้อย เพราะหน้าเว็บเป็นตัววาดและอธิบายเอง agent จึงเขียนเนื้อหาแค่ครั้งเดียว หลังจากนั้นแทบไม่ต้องใช้อะไรเพิ่ม

| ค่าใช้จ่าย | หน้าอธิบายที่ agent เขียนเอง | Walkboard |
|---|---|---|
| แผนเต็มๆ ที่มี 4 ภาพ | HTML และ SVG 26–43 KB เขียนใหม่ทุกครั้งที่แก้ | `plan.json` ประมาณ 7 KB เขียนครั้งเดียว แผนง่ายๆ ประมาณ 0.5 KB |
| ขยับขั้นตอนไปข้างหน้า | เขียนหรือแก้หน้าเว็บใหม่ | `walkboard set … step:x status=review` คำสั่งเดียว ประมาณ 90 bytes |
| แสดงโค้ดในโหมดอธิบาย | แปะโค้ดลงไป | แค่ `file:line` กับบรรทัดที่จะไฮไลต์ server อ่านโค้ดให้เอง |
| อธิบายศัพท์ทั่วไป | อธิบายใหม่ทุกครั้ง | Walkboard มีศัพท์ติดมาประมาณ 95 คำ ทั้งภาษาอังกฤษและภาษาไทย |
| แต่ละข้อความจากหน้าเว็บ | — | บรรทัดสั้นๆ บรรทัดเดียว ประมาณ 100–150 bytes |
| สลับว่าใครเป็นคน commit | — | ไม่เสียเลย agent อ่านค่าที่ตั้งไว้ตอนได้ข้อความถัดไปหรือตอนเริ่มขั้นถัดไป |
| คำสั่งที่โหลดมากับ skill | — | SKILL.md ประมาณ 8.5 KB ที่เหลืออยู่ในไฟล์เล็กๆ ที่ agent อ่านเฉพาะตอนต้องใช้ map บน AWS กับการรีวิวหนึ่งครั้งอ่านไปทั้งหมด 27 KB |

ทุกข้อความจากหน้าเว็บปลุก agent หนึ่งครั้ง และ agent จะอ่านบทสนทนาใหม่ ซึ่งส่วนใหญ่มาจาก cache การตั้งค่าไม่ปลุก agent เลย มีแค่ข้อความที่ต้องตอบเท่านั้นที่นับเป็นหนึ่งรอบ

## อัปเดตและถอนการติดตั้ง

```
/plugin marketplace update walkboard
/plugin uninstall walkboard@walkboard
```

ถ้าติดตั้ง Walkboard เองด้วยมือ ให้ pull ใหม่เพื่ออัปเดต หรือลบ `~/.claude/skills/walkboard` เพื่อถอนการติดตั้ง แผนของคุณจะยังอยู่ใน `~/.walkboard/` จนกว่าคุณจะลบเอง
