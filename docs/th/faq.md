# คำถามที่พบบ่อยและข้อจำกัด

คำตอบของคำถามที่คนถามบ่อยที่สุด และสิ่งที่ Walkboard ยังทำไม่ได้

## ทำให้ใช้งานได้

### ไม่เห็น `/walkboard` ในเมนู

ลองเปิด session ใหม่ หรือรัน `/reload-plugins` ถ้ายังไม่เห็น เปิด `/plugin` แล้วดูว่าติดตั้งและเปิดใช้ walkboard อยู่ไหม

ถ้ามี plugin อื่นใช้ชื่อคำสั่ง `/walkboard` ไปแล้ว ให้พิมพ์ `/walkboard:walkboard` แทน หรือจะขอเป็นคำพูดธรรมดาก็ได้ เช่น "ขอดูการทำงานของ login เป็นภาพ"

### คลิกแล้วไม่มีอะไรเกิดขึ้น หรือหน้าเว็บบอกว่าเปิดจากไฟล์

น่าจะเปิดไฟล์ HTML ตรงๆ อยู่ ต้องเปิดลิงก์ `http://127.0.0.1:…/?token=…` ที่ agent ส่งมา ถ้าลิงก์หาย บอก agent ว่า "ขอลิงก์ walkboard อีกที"

### จุดสถานะบอกว่า agent ติดงานอื่น

แปลว่า agent กำลังทำอย่างอื่นอยู่ เช่น เขียนโค้ดหรือรัน test ข้อความของคุณจะเข้าคิวรอไว้ แล้ว agent จะได้รับเมื่อว่าง ถ้าอยากเร่ง พิมพ์ในแชทของ agent ว่า "ดูหน้า walkboard" (ใช้คำไหนก็ได้)

ถ้าสถานะขึ้นว่า **✉ ไม่ได้ฟังสด: บอก agent ในแชท** แทน แปลว่า agent ของคุณไม่ตื่นขึ้นมาจากหน้าเว็บเลย agent ส่วนใหญ่ที่ไม่ใช่ Claude Code ทำงานแบบนี้ พออยากให้มันอ่านหน้าเว็บ ก็บอกมันในแชท ดู [ใช้กับ agent อื่น](other-agents.md)

### หน้าเว็บยังเป็นเวอร์ชันเก่ากว่าที่ติดตั้ง

session ที่เปิดอยู่จะใช้เวอร์ชันเดิมที่มันเริ่มไว้ รัน `/reload-plugins` หรือเปิด session ใหม่ แล้วให้ agent เปิดแผนอีกครั้ง หน้าเว็บจากเวอร์ชันเก่าจะถูกแทนที่ เลขเวอร์ชันดูได้ที่บรรทัดล่างสุดของเมนู **⋮**

### agent ถาม permission ทุกครั้งที่แก้แผน

ไปตั้ง permission ของ agent ให้อนุญาตคำสั่ง `node …/skills/walkboard/bin/walkboard.mjs` และการแก้ไฟล์ใน `~/.walkboard/`

### server ดูเหมือนค้าง หรือ port ถูกใช้อยู่

บอก agent ให้ restart server ของ Walkboard มันจะรัน `walkboard stop` แล้วตามด้วย `walkboard open` กับ folder ของแผน ลิงก์ยังเป็นอันเดิม

## ความเป็นส่วนตัวและความปลอดภัย

### โค้ดจะออกไปนอกเครื่องไหม

หน้าเว็บและ server ของ Walkboard อยู่ในเครื่องคุณทั้งหมด server รับการเชื่อมต่อจาก 127.0.0.1 เท่านั้น และต้องมี token ที่สุ่มขึ้นมา (เหมือน password ที่ติดมากับลิงก์) มันไม่ส่ง request ออกไปทาง network และไม่เก็บ telemetry

ส่วนตัว agent ก็ทำงานเหมือนทุกครั้ง สิ่งที่มันอ่านเพื่อทำแผนจะถูกส่งไปที่ model เหมือน session อื่นๆ รายละเอียดอยู่ใน [SECURITY.md](../../SECURITY.md)

### จะไปแก้อะไรใน cloud account ไหม

ไม่แก้อะไรเลย ในโหมดออกแบบ agent อาจอยากดูว่ามีอะไรอยู่จริง มันจะใช้แค่คำสั่งที่อ่านอย่างเดียว เช่น `describe` `list` `get` และถามคุณก่อนทุกครั้ง หรือส่งคำสั่งมาให้คุณรันเอง

### เพื่อนร่วมทีมเปิดหน้าเว็บของฉันได้ไหม

ไม่ได้ หน้าเว็บรันอยู่ในเครื่องคุณ ลิงก์จึงใช้ได้แค่ในเครื่องนั้น ถ้าอยากให้เขาดูแผน [ส่งสำเนาไปให้](share.md) หรือแชร์ `plan.json` ของแผน

### แผนเก็บไว้ที่ไหน

อยู่ใน `~/.walkboard/<project>/<task>/` ยกเว้นคุณเลือก folder อื่น ถ้าอยากลบแผนพร้อมบทสนทนา ลบ folder นั้นได้เลย

## การใช้งาน

### วาดระบบที่มีอยู่แล้วได้ไหม

ได้ บอก agent เช่น "อธิบาย network บน AWS จาก Terraform ใน folder infra/" agent จะอ่านสิ่งที่อยู่ใน repository เช่น Terraform, Kubernetes manifest หรือ Compose file แล้ววาดออกมาเป็น [map](pictures/map.md) ดู [วาดระบบที่มีอยู่แล้ว](existing.md)

### กิน token เยอะไหม

**token** คือหน่วยที่ model ใช้นับข้อความ ยิ่งใช้เยอะยิ่งเปลือง Walkboard ใช้น้อยกว่าให้ agent เขียนหน้า HTML เอง เพราะ agent เขียนไฟล์ JSON เล็กๆ แค่ไฟล์เดียว แล้วแก้ด้วยคำสั่งบรรทัดเดียว ทุกข้อความที่ส่งจากหน้าเว็บนับเป็นหนึ่งรอบของ agent ส่วนการเปลี่ยน setting การจัดภาพ และการร่างการแก้ไข ไม่ส่งไปถึง agent จึงไม่เสียอะไรเลย ตัวเลขอยู่ใน[หน้า reference](reference.md#tokens)

### ใช้กับ agent อื่นได้ไหม

ได้ agent ที่อ่าน skill แบบ `SKILL.md` เช่น Codex, Gemini CLI หรือ Cursor ได้ภาพและหน้าเว็บเหมือนกัน ต่างกันแค่ agent ส่วนใหญ่ไม่ตื่นขึ้นมาเองเวลาคุณคลิก ข้อความบนหน้าเว็บจึงรอไว้ จนกว่าคุณจะพิมพ์บอก agent ในแชทว่า "ดูหน้า walkboard" ตอนนี้ใช้จริงทุกวันกับ Claude Code และลองครบทุกขั้นกับ OpenCode แล้ว [ใช้กับ agent อื่น](other-agents.md) บอกวิธีติดตั้งและสิ่งที่จะเจอ

## ข้อจำกัด

สิ่งที่ Walkboard ยังทำไม่ได้มีดังนี้

- ปุ่มและ label บนหน้าเว็บมีแค่ภาษาอังกฤษกับภาษาไทย ตัวแผนจะเป็นภาษาอะไรก็ได้
- หน้าเว็บหนึ่งหน้าใช้ได้คนเดียวบนเครื่องเดียว หลายคนแก้พร้อมกันไม่ได้
- ข้อความแต่ละข้อความส่งถึง agent ได้ครั้งเดียว ถ้า agent หยุดทำงานทันทีหลังได้รับข้อความ ให้ส่งใหม่อีกครั้ง
- Walkboard สร้างและใช้งานบน macOS กับ Chrome ทั้งใน terminal และแอป Claude desktop automated test รันบน Linux และ Windows ด้วย แต่ยังไม่มีใครลองใช้จริงด้วยมือ
- ภาพที่มีเส้นเป็นพันๆ เส้นจะ render ใหม่ช้า
- เวลาพิมพ์ภาพที่ใหญ่มาก ภาพรวมจะเห็นแค่รูปร่างคร่าวๆ รายละเอียดให้ดูในส่วนที่ตามมา
