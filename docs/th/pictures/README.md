# Pictures (ภาพทั้ง 11 แบบ)

Walkboard วาดแผนหรือคำอธิบายออกมาเป็นภาพหนึ่งหรือสองภาพ ภาพมีทั้งหมด 11 แบบ แต่ละแบบตอบคำถามคนละแบบ agent จะเลือกแบบที่เข้ากับสิ่งที่คุณถามให้เอง คุณไม่ต้องเลือก

หน้านี้อธิบายว่าภาพแต่ละแบบอ่านยังไง และทำอะไรบนภาพได้บ้าง

## เลือกภาพให้ตรงกับคำถาม

| ถ้าคำถามคือ | ภาพที่ได้ | ร่างบนภาพได้ไหม |
|---|---|---|
| มีขั้นตอนอะไรบ้าง เรียงยังไง | [Flow](flow.md) | ✓ |
| อะไรอยู่ข้างในอะไร และอยู่บนแพลตฟอร์มไหน | [Map](map.md) | ✓ |
| ใครเรียกใคร ลำดับยังไง และถ้าพังจะเกิดอะไร | [Sequence](sequence.md) | |
| ข้อมูลหน้าตาเป็นยังไงก่อนและหลัง | [Transform](transform.md) | |
| ข้อมูลชิ้นหนึ่งเจออะไรบ้างระหว่างทาง | [Journey](journey.md) | |
| มันอยู่ในสถานะไหนได้บ้าง และอะไรทำให้เปลี่ยน | [State](state.md) | ✓ |
| ถ้าเป็นแบบนี้ แล้วไปทางไหน | [Decision](decision.md) | ✓ |
| เกิดขึ้นตอนไหน และนานเท่าไร | [Timeline](timeline.md) | |
| มีตารางอะไร คีย์อะไร และเชื่อมกันยังไง | [Data model](datamodel.md) | ✓ |
| ถ้าตัวนี้ล่ม อะไรพังบ้าง | [Impact](impact.md) | ✓ |
| ตอนนี้กับหลังทำเสร็จ ต่างกันตรงไหน | [Before and after](diff.md) | ร่างผ่านสองภาพที่มันเทียบ |

ขอภาพแบบที่ต้องการเองก็ได้ เช่น "ขอดูการ retry เป็น timeline"

## คลิกกล่อง

ทุกกล่องในทุกภาพคลิกได้ กล่องเดียวกันจะเปิดรายละเอียดและบทสนทนาชุดเดียวกันไม่ว่าจะอยู่ในภาพไหน คำถามที่คุณถามไว้บน flow จึงยังอยู่ตอนไปเจอกล่องเดียวกันบน map

บนหน้าเว็บ ปุ่ม **?** ข้างแท็บภาพจะบอกความหมายของสีและเครื่องหมายในภาพที่เปิดอยู่ และมีลิงก์กลับมาที่หน้าคู่มือของภาพนั้น

## เครื่องหมายที่ใช้เหมือนกันทุกภาพ

| เครื่องหมาย | ความหมาย |
|---|---|
| สีเขียวมี ✓ | ทำแล้ว |
| ● | กำลังทำ หรือเพิ่งทำเสร็จ |
| ขอบเส้นประ | ยังไม่ได้ทำ |
| ↗ | ระบบภายนอก ไม่ได้อยู่ในงานนี้ |
| สีเทา | โค้ดที่มีอยู่แล้ว และงานนี้ไม่ได้แก้ |
| เส้นประมี ❓ | สิ่งที่ agent สมมติไว้ กด **✎ ตอบ** เพื่อบอกว่าความจริงเป็นยังไง |
| 💬 | มีบทสนทนาบนกล่องนี้ |
| **+** **~** **−** | การแก้ที่ agent เสนอหลังอนุมัติแผนไปแล้ว คือเพิ่ม เปลี่ยน หรือเอาออก |

พอเลือกขั้นไหน ทุกอย่างที่ขั้นนั้นไม่ได้แตะจะจางลง

## จัดภาพและร่างการแก้ไข

ภาพ map, data model, state, decision และ impact ลากกล่องเพื่อจัดให้อ่านง่ายได้ การจัดภาพแค่ย้ายตำแหน่งบนจอ ไม่เปลี่ยนแผน และไม่ไปขัดจังหวะ agent ถ้าอยากให้หน้าเว็บจัดภาพให้ใหม่ กด **↺ จัดภาพใหม่**

ถ้าอยากเปลี่ยนสิ่งที่ภาพบอก ให้ใช้[โหมดร่าง](../draft.md)แทน
